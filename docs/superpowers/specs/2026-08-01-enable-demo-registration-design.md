# Demo 环境开放注册设计

## 目标

允许当前通过生产部署脚本运行的 Demo 环境使用邮箱和密码注册新用户。

## 行为

- `AUTH_REGISTRATION_ENABLE` 的部署有效值改为 `true`。
- `AUTH_REGISTRATION_DEV_ROLE_SELECTION` 的部署有效值改为 `true`。
- 注册页面显示角色选择器，允许 Demo 用户选择 `viewer` 或 `system_admin`；未选择时仍使用默认角色 `viewer`。
- OIDC/SSO 保持当前临时禁用状态，相关 CI 兼容开关和认证代码不变。

## 修改范围

- 调整生产部署脚本的注册有效值和校验。
- 调整生产 Compose 覆盖中的注册有效值。
- 更新生产环境示例，使其与部署行为一致。
- 更新部署脚本测试，验证注册和角色选择均已开启，同时保持 OIDC 临时兼容行为。

## 非目标

- 不修改前端登录或注册组件。
- 不修改后端注册接口和权限逻辑。
- 不启用或删除 OIDC/SSO。
- 不修改数据库结构或数据。

## 验证

- 运行生产部署脚本测试。
- 验证渲染后的 Compose 配置中注册和开发角色选择均已开启。
- 验证 OIDC 仍可通过现有临时兼容开关保持关闭。
