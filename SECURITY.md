# Security Policy

Security issues must be reported through the Roche project security process or directly to the designated system owner. Do not disclose credentials, personal data, internal URLs, access tokens, or vulnerability details in public channels.

Include the following information when reporting an issue:

- affected environment and version
- reproducible steps
- observed and expected behavior
- potential impact
- relevant logs with secrets removed

The project owner will acknowledge the report, coordinate investigation, and communicate remediation and deployment plans through approved internal channels.
